# Python Programming

This repository contains exercises for a Python programming course. The purpose of the exercises is to practice Python programming at different levels, covering various topics such as basic structures, data structures, functions, and file handling.

## Contents

The exercises are divided into the following categories:
- **Basics**: variables, conditional statements, loops
- **Data Structures**: lists, tuples, dictionaries
- **Functions**: creating and using custom functions
- **File Handling**: reading from and writing to files
- **Modules and Libraries**: using Python's built-in libraries
- **Object-Oriented Programming**: classes and objects
